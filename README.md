# ポモドーロタイマー

ブラウザで動くシンプルなポモドーロテクニック用タイマーです。インストールやビルドは不要です。

## 使い方

`index.html` をブラウザで開くだけで使えます。

1. 「開始」で 25 分の作業を始めます
2. 終わると音（と通知）が鳴り、自動で休憩モードに切り替わります
3. 4 ポモドーロごとに長い休憩（15 分）、それ以外は短い休憩（5 分）になります

## 機能

- 作業 / 短い休憩 / 長い休憩 の自動切り替え
- 円形のプログレス表示と、タブのタイトルに残り時間を表示
- 開始・一時停止・リセット・スキップ
- 今日完了したポモドーロ数と、長い休憩までの進み具合を表示
- 時間・長い休憩までの回数・自動開始・音・デスクトップ通知を設定可能（設定はブラウザに保存）
- キーボードショートカット: `Space` 開始/停止、`R` リセット、`S` スキップ
- ダークモード対応

## ファイル構成

- `index.html` — 画面
- `style.css` — デザイン
- `app.js` — タイマーのロジック
