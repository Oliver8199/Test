# 資料スクロール撮影 → PDF ツール

ブラウザで開いた講座資料を**自動でスクロールしながらスクショ**し、1つのPDFにまとめます。
同時にページ内の**テキストも `.md` に書き出す**ので、Claude Code での解析・図解化に使えます。

- ログインが必要なページでも、表示したブラウザで自分でログインしてから撮影できます（ログイン状態は次回以降も保存されます）
- Notion のように「ページの中の一部分だけがスクロールする」資料にも自動で対応します
- 複数のページ（第1回、第2回…）を順番に撮って、1つのPDFにまとめられます

> ⚠️ 撮影した資料は自分の学習用だけに使ってください。再配布はせず、講座の利用規約も確認してください。

## 準備（最初の1回だけ）

Python 3.9 以上が必要です。

```bash
cd capture_to_pdf
pip install -r requirements.txt
python -m playwright install chromium
```

（PCに Google Chrome が入っているなら、最後の行の代わりに実行時に `--channel chrome` を付けても動きます）

## 使い方

```bash
python capture.py "https://資料のURL" -o 講座資料.pdf
```

1. ブラウザが開きます。初回はここで講座サイトにログインしてください
2. 撮りたい資料のページを表示したら、ターミナルで **Enter**
3. 自動でスクロールしながら撮影されます
4. 次のページも撮るなら、ブラウザでそのページを開いてもう一度 **Enter**
5. 終わったら **q + Enter** で、PDF を保存します

できるファイル:

| ファイル | 中身 |
|---|---|
| `講座資料.pdf` | スクショをまとめたPDF |
| `講座資料.md` | ページ内のテキスト（Claude に解析させるならこちらが正確） |

## よく使うオプション

| オプション | 説明 |
|---|---|
| `--wait 1.5` | 画像の読み込みが遅いページで、スクロール後の待ち時間を延ばす |
| `--width 1000` | ブラウザの幅を変える（狭いと文字が大きく写る） |
| `--save-png` | PDFとは別に、1枚ずつのPNG画像も保存する |
| `--channel chrome` | PCに入っている Google Chrome を使う |

## 撮ったあと：Claude Code で図解資料にする

`.md`（テキスト）と `.pdf`（図や画面の様子）を Claude Code に渡して、次のように頼みます。

```
講座資料.md と 講座資料.pdf を読んで、内容を初心者向けに図解した資料にしてください。
- 章ごとに要点を3つまでにまとめる
- 手順はフローチャートにする
- 用語は一覧表にして、やさしい言葉で説明する
```

## うまくいかないとき

- **途中で撮影が止まる／下まで行かない**: `--wait 2` で待ち時間を延ばしてください
- **関係ない場所（サイドバーなど）が写る**: ブラウザの幅を変えるか、資料本文を1回クリックしてから Enter を押してください
- **Google ドキュメントなど**: テキストは取れないことがあります。その場合は PDF 側を Claude に読ませてください
